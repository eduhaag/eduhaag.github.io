Em desenvolvimento

Aplicativo para Nuvemshop

Conferência de expedição com prova

Aplicativo para pequenas e médias lojas virtuais que evita o envio de produto errado e registra uma prova de cada embalagem, usando apenas o celular, sem leitor dedicado e sem ERP.

  • Conferência de cada item do pedido pela câmera do celular, com alerta de produto ou quantidade incorretos
  • Atualização automática do status do pedido para "embalado" via API da Nuvemshop
  • Foto da embalagem vinculada ao pedido, como evidência em caso de reclamação
  • Geração de etiquetas de código de barras para produtos que não possuem GTIN

Stack: Node.js · React (PWA) · PostgreSQL · API e webhooks da Nuvemshop
